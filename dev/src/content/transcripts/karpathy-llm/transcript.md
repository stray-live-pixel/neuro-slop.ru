# Полная расшифровка — справочный файл

Сюда кладётся полная расшифровка видео, которую присылают агенты соседнего проекта.
Этот файл **не публикуется**: коллекция Astro грузит только `index.md` каждой папки
(см. `dev/src/content.config.ts`, паттерн `**/index.md`). Расшифровка остаётся рядом
со статьёй как источник — чтобы при доработке разбора было что перечитать.

> Для статьи-примера (вводная лекция Карпаты) полная расшифровка не прикладывалась —
> разбор собран по содержанию лекции. Замени этот файл реальной расшифровкой при наличии.
