# Расшифровка — указатель на приватную логику

Полная логика этого скилла хранится в **приватном** репозитории `private-neuro-slop`
(на этом пайплайне можно зарабатывать, поэтому в публичном репозитории его нет —
см. раздел «Два репозитория» в `CLAUDE.md`/`AGENTS.md`). Здесь — только указатель.

## Что делать

1. **Прочитай** файл с полной логикой:
   `../private-neuro-slop/.claude/skills/rasshifrovka/SKILL.md`
   или symlink-путь для Codex:
   `../private-neuro-slop/.codex/skills/rasshifrovka/SKILL.md`
   (абсолютный путь: `/Users/kirilleremin/Documents/dev/private-neuro-slop/.claude/skills/rasshifrovka/SKILL.md`).
2. **Выполни** его инструкции для запроса пользователя. Передай в него:
   - источник (YouTube-ссылка / ссылка на статью / путь к аудио-видео-файлу / путь к расшифровке / вставленный текст);
   - любые пометки про приватность и публикацию («приватно», «публично», «не публикуй»).

Кратко, что делает та логика (полный цикл):
1. Проверяет, нет ли уже готовой расшифровки (вдруг сделана руками).
2. Если нет — скачивает аудио и расшифровывает (для видео/аудио).
3. Прогоняет расшифровку через deep-research агента и собирает разбор.
4. Публикует статью на сайт — **кроме случая, когда контент помечен как приватный**
   (для YouTube или явно публичного контента публикует сразу, без вопросов).

## Если приватный репозиторий не найден

Если по указанному пути нет `private-neuro-slop` — сообщи пользователю, что для этого
скилла нужна папка `private-neuro-slop` рядом с этим репозиторием, и не продолжай.
