# 2D-ассеты для игр — указатель на приватную логику

Полная логика этого скилла (и ключ OpenRouter) хранится в **приватном**
репозитории `private-neuro-slop` (на генерации ассетов можно зарабатывать,
поэтому в публичном репозитории её нет — см. раздел «Два репозитория» в
`CLAUDE.md`/`AGENTS.md`). Здесь — только указатель.

## Что делать

1. **Прочитай** файл с полной логикой:
   `../private-neuro-slop/.claude/skills/game-asset/SKILL.md`
   или symlink-путь для Codex:
   `../private-neuro-slop/.codex/skills/game-asset/SKILL.md`
   (абсолютный путь: `/Users/kirilleremin/Documents/dev/private-neuro-slop/.claude/skills/game-asset/SKILL.md`).
2. **Выполни** его инструкции для запроса пользователя. Передай в него:
   - описание ассета (что нарисовать);
   - статика или анимация (и что именно анимируется: бег, флаг, мигание…);
   - стиль/вид и для какой игры (`/lab/<game>/`), если указаны.

Кратко, что делает та логика:
1. Собирает грамотный промпт (объект на плоском однотонном фоне).
2. Рисует картинку через OpenRouter (`google/gemini-3.1-flash-image`).
3. Снимает фон → прозрачный PNG; для анимаций режет спрайт-лист на кадры и
   собирает анимированное превью.
4. Готовый ассет можно скопировать в публичный репо рядом с игрой
   (`dev/public/lab/<game>/assets/`).

## Если приватный репозиторий не найден

Если по указанному пути нет `private-neuro-slop` — сообщи пользователю, что для
этого скилла нужна папка `private-neuro-slop` рядом с этим репозиторием (там ключ
OpenRouter и логика генерации), и не продолжай.
