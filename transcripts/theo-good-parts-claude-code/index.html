Его цель — чтобы все остальные инструменты для разработки скопировали эти удачные приёмы. Простыми словами. Claude Code — это программа в терминале, где искусственный интеллект пишет код за тебя. У неё есть удобные мелочи, которых нет у конкурентов. Например, скилл — это шпаргалка для ИИ, которая в Claude Code умеет сразу запустить скрипт и подгрузить нужные данные. Можно собрать инструкции из нескольких файлов одной строчкой, держать личные настройки отдельно от командных, задать побочный вопрос, не прерывая основную работу, и откатить историю назад, если ошибся. Стоит ли смотреть? Да, если вы пишете код с ИИ. Видео плотное и практичное, минус — рекламная вставка и эмоциональные отступления. Полезнее всего оно инженерам по искусственному интеллекту и обычным программистам. Самое сильное здесь — воркфлоу. Искусственный интеллект сам пишет одноразовый код, который разбивает большую задачу на этапы и раздаёт их десяткам мелких агентов. Тео формулирует это так: невозможно быть динамичнее, чем код. Но за мощь приходится платить — около ста долларов за десять минут работы. Что попробовать на практике. Сделайте свой главный файл инструкций общим через импорт, держите личные правки в отдельном файле вне репозитория и переключайте аккаунт заранее, чтобы долгий прогон не оборвался на лимите. А вот что стоит поставить под сомнение. Тео называет приём со сменой аккаунтов восхитительным, но по сути это обход лимитов на грани правил сервиса. И напоследок — взгляд под другим углом. Это напоминание: модель — не библиотека, которую установил навсегда, а сервис, зависящий от юрисдикции.

Объясни проще

Суть без жаргона

Простыми словами

Claude Code — это терминальная программа, в которой ИИ пишет код за тебя. У неё есть набор удобных мелочей, которых нет у конкурентов: скиллы (текстовые инструкции для ИИ) могут сразу запускать скрипт и подгружать данные заранее; инструкции собираются из нескольких файлов одной строчкой; есть личные настройки, не мешающие команде, побочные вопросы без прерывания работы, откат истории и управление с телефона. Самое мощное — «воркфлоу»: ИИ сам пишет одноразовый код, который разбивает большую задачу на этапы и раздаёт их десяткам мелких агентов.

Как ребёнку

Представь робота-помощника, который делает за тебя домашку по программированию. У него есть кнопки, которых нет у других роботов: шпаргалка, которая сама открывается на нужной странице; можно спросить о чём-то, не отвлекая от главного дела; можно отменить последний шаг. А ещё он умеет позвать кучу маленьких роботов и раздать им части задачи. Мальчик в видео говорит: «Пусть все роботы научатся так же!»

Аналогия — «это как…»

Это как разница между шпаргалкой и ассистентом, который сам сбегал в библиотеку и принёс нужные книги ещё до того, как ты спросил: обычный скилл просто говорит ИИ «сделай шаг», а исполняемый скилл сам подготавливает данные при загрузке.

Зачем это мне

Агентные CLI становятся главным способом писать код с ИИ, а фичи мигрируют между ними почти мгновенно. Понять, какие паттерны делают инструмент удобным сегодня, — значит уметь выбирать harness и не переплачивать за оркестрацию завтра.

Для тех, кто в теме

Самое ценное — code mode: агент пишет ~240 строк одноразового JS с глобальным хелпером pipeline, сам определяя фазы audit→rule→verify и до 8 параллельных readonly-сабагентов. Плюс исполнение скрипта при загрузке скилла, рекурсивные @-импорты (до 4 хопов), горячая смена OAuth между tool call'ами и deep links claude-code://.

Ядро аудитории: code mode и workflows (агент пишет ~240 строк JS, фазы audit→rule→verify, до 8 параллельных сабагентов), исполняемые скрипты в скиллах, приёмы промптинга моделей под их ошибки — прямо в задачи по проектированию агентных пайплайнов.

Для DevOps-инженеров 3 /5

Запуск Claude Code на других машинах в сети, scroll в tmux по SSH, deep links и быстрая CI-петля для агентов — но не основной фокус.

Для технических-блогеров 3 /5

Образец честного разбора инструмента и тезис об эволюции стандартов разработки.

Инсайты

Нажми, чтобы раскрыть — то, что меняет взгляд на тему

01 Скилл может запускать скрипт при загрузке, а не после 3:31

Claude Code выполняет скрипт в момент загрузки скилла и подгружает данные в контекст заранее (listing кэша репозиториев). Это убирает целый шаг — скилл становится короче и надёжнее.

02 Код динамичнее любой фиксированной фичи 18:22

Когда агент пишет код для воркфлоу, он каждый раз строит себе кастомную фичу под задачу. Код — это шаг между запусками модели, а не только их вывод.

03 Аккаунт можно сменить на лету, не убив запущенный воркфлоу 24:43

Новый OAuth применяется со следующего API-запроса: текущая генерация дойдёт на старом аккаунте, а следующий tool call — на новый. «Awesome and really abusable».

04 Fable и Opus по-разному относятся к чужому коду 20:42

Opus 4.8 расхваливал код от GPT, а Fable его терпеть не может и в воркфлоу прямо «refuted» PR, написанный моделью 5.5 — наблюдение о различии «характеров» моделей при ревью.

05 Разные стандарты файлов — не зло, а пространство для улучшений 6:36

Отдельный «особый» файл Anthropic даёт свободу делать вещи, которые сломались бы в общем AGENTS.md; стандарт должен двигаться и улучшаться.

Полезные советы

Что можно применить уже сегодня. Разверни совет — сколько займёт, что даст и что конкретно делать

1

Подгружай данные в скилл скриптом на старте

15 минут скилл вдвое короче и не тратит шаг на разведку

Вынеси первый шаг (листинг, подготовку данных) в исполняемый скрипт скилла — он отработает при загрузке, и модель получит готовый контекст сразу.

Что делать

  1. 1 Найди в скилле первый шаг, где модель просто собирает данные (листинг, чтение кэша).
  2. 2 Вынеси его в скрипт, который скилл запускает при загрузке.
  3. 3 Удали этот шаг из текста скилла — данные уже в контексте.
2

Сделай CLAUDE.md = AGENTS.md без симлинков

5 минут один источник правды без дублей и symlink-костылей

Впиши строку @AGENTS.md внутрь CLAUDE.md — весь AGENTS.md подтянется в контекст, а ниже можно дописать инструкции только для Claude.

Что делать

  1. 1 Открой CLAUDE.md в корне репозитория.
  2. 2 Добавь первой строкой @AGENTS.md.
  3. 3 Ниже допиши только Claude-специфичные инструкции, если нужны.
3

Заведи claude.local.md для личных настроек

10 минут твои оверрайды не попадут в репозиторий и не конфликтуют с командой

Держи личные предпочтения в claude.local.md и добавь файл в глобальный gitignore.

Что делать

  1. 1 Создай claude.local.md и впиши туда личные предпочтения.
  2. 2 Добавь claude.local.md в глобальный ~/.gitignore.
  3. 3 Проверь, что файл не виден в git status.
4

Не запускай /init — пиши CLAUDE.md руками

полчаса чистые инструкции без мусора автогенерации

Автогенерация даёт плохой результат; лучше написать вручную и подтянуть README/package.json через @path-импорты.

Что делать

  1. 1 Создай CLAUDE.md вручную, без /init.
  2. 2 Подтяни нужные файлы строками @README.md, @package.json.
  3. 3 Опиши коротко правила проекта своими словами.
5

Спрашивай side-вопрос через /by-the-way

1 минута получаешь ответ, не сбивая основной агент с задачи

Пока агент делает задачу, получи отдельный под-чат, не прерывая основной разговор. В Codex аналог — /side.

6

Переключай аккаунт до упора в лимит, а не после

2 минуты долгий воркфлоу не оборвётся на середине

Боишься упереться в usage-лимит на середине воркфлоу — смени аккаунт заранее, новый OAuth подхватится со следующего tool call.

Что делать

  1. 1 Заведи запасной аккаунт с активной подпиской.
  2. 2 Перед длинным прогоном переключи OAuth-аккаунт.
  3. 3 Текущая генерация дойдёт на старом, следующие запросы — на новом.
7

Включи flickerless full-screen рендерер

2 минуты полноэкранный режим без мерцания и мусора в scroll-buffer

Команда /tui full-screen или переменная CLAUDE_NO_FLICKER=1.

Что делать

  1. 1 Выполни /tui full-screen внутри Claude Code.
  2. 2 Либо выставь переменную окружения CLAUDE_NO_FLICKER=1.
8

Используй rewind для отката, branch — для развилки

1 минута исправляешь ошибку без перезапуска сессии

Случайно отправил не то — откати на шаг-два через rewind (но fast-forward почти невозможен); хочешь увести историю в другую сторону — branch.

9

Запускай сессии по deep links

полчаса кнопка «запустить агента» прямо в плане задачи

claude-code:// открывает сессию из ссылки на HTML-странице с планом, передавая рабочую директорию и GitHub-репо.

Что делать

  1. 1 Сгенерируй HTML-страницу с планом задачи.
  2. 2 Вставь ссылку claude-code:// с рабочей директорией и репо.
  3. 3 Кликни ссылку — откроется сессия с нужным контекстом.
10

Удешеви воркфлоу более дешёвыми моделями

15 минут расход usage станет заметно мягче

Воркфлоу на Fable жгут ~$100 за 10 минут; поручи под-агентов Sonnet и Opus вместо Fable.

Что делать

  1. 1 Открой конфиг воркфлоу с распределением под-агентов.
  2. 2 Замени Fable на Sonnet/Opus для readonly-сабагентов.
  3. 3 Прогони и сравни расход usage до и после.

Theo с канала t3.gg начинает с признания: это видео он делать не хотел. Он открыто критикует Anthropic, но за последние дни так много работал в Claude Code, что нашёл десяток мелочей, которые тот делает лучше любого другого агентного CLI. Главный мотив видео — не реклама (Anthropic не спонсор), а призыв к остальным harness’ам украсть эти удачные паттерны.

Хорошие части по порядку

Исполняемые скиллы. В Claude Code скилл может запускать скрипт прямо при загрузке и подкладывать данные в контекст заранее — например, листинг кэша репозиториев. Это убирает целый шаг, который иначе модель делает вручную, и делает скилл короче и надёжнее. Опасения про «arbitrary execution» Theo считает преувеличенными: по его словам, это не опаснее npm.

Импорты инструкций. CLAUDE.md умеет рекурсивные @path-импорты (до 4 хопов), а трюк со строкой @AGENTS.md делает CLAUDE.md и AGENTS.md одним и тем же без симлинков. Личные предпочтения выносятся в claude.local.md через gitignore, чтобы не конфликтовать с командой. Отсюда тезис: общий стандарт не должен застывать — у вендора есть право двигать его и делать вещи лучше.

Навигация и удобства. Deep links claude-code:// запускают сессию прямо из HTML-страницы с планом; /by-the-way даёт побочный под-чат, не прерывая основную работу; эфемерные worktrees удобны под одноразовые PR; rewind откатывает историю, branch уводит её в новое русло; flickerless full-screen и remote control с телефона добивают список.

Главное — воркфлоу и code mode

Сильнейшая часть видео — воркфлоу в code mode: агент сам пишет ~240 строк одноразового JS, который через глобальный хелпер pipeline разбивает задачу на фазы audit→rule→verify и раздаёт их десяткам параллельных readonly-сабагентов. Ключевая мысль Theo: «невозможно быть динамичнее, чем код» — написав код, агент каждый раз строит себе кастомную фичу под задачу, и код становится шагом между запусками модели, а не только их выводом.

Цена этой силы — бешеный расход: около $100 за 10 минут на одном воркфлоу. Отсюда же приём со сменой аккаунта на лету (новый OAuth подхватывается со следующего tool call) — «awesome and really abusable». А прямо по ходу записи выходит новость: правительство США потребовало приостановить доступ к Fable и Mythos для иностранцев — напоминание, что модель сегодня не библиотека «навсегда», а юрисдикционно-зависимый сервис.

Режим, когда агент пишет настоящий код (а не просто текст с вызовами тулов) для оркестрации; код — шаг между запусками модели.

Критический взгляд

Объективно: с какими тезисами можно поспорить и что преувеличено

Однобоко

Риски arbitrary execution в скиллах преувеличены («не опаснее npm»)

npm-пакет надо явно установить, а скилл с исполняемым скриптом срабатывает при загрузке. Это подтверждённый класс RCE: CVE-2025-59536 (CVSS 8.7) и CVE-2026-21852, а не паранойя сообщества.

Спорно

Возражение специалиста по безопасности подаётся как overreaction

Theo пересказывает, что друг Mario счёл pi-скилл небезопасным, но сводит спор к «get over yourselves» — подмена технического аргумента эмоцией.

Однобоко

Смена аккаунтов на лету («awesome and really abusable») подаётся как полезный приём

По сути это обход usage-лимитов, против которого Anthropic ввела окна и капы. Приём балансирует на грани ToS и риска бана.

Преувеличение

Workflows в code mode — «код динамичнее любой фичи», значит лучший паттерн

Динамичность оплачивается ценой и надёжностью (~$100/10 мин, иногда невалидный JS); одноразовый код невоспроизводим и не аудируется до запуска.

Упрощение

Трюк @AGENTS.md решает проблему конкурирующих стандартов

CLAUDE.md тянет AGENTS.md, но не наоборот, и только внутри Claude Code; фрагментация остаётся, а vendor-специфичный файл закрепляется.

Спорно

«Стандарт должен двигаться», значит отход Anthropic оправдан

Тезис обходит цену: lock-in и двойная работа. «Двигать стандарт» в одиночку ≠ «улучшать» его — нужно согласование, иначе это фрагментация под брендом прогресса.

Взгляни иначе

Новый угол, смежные области и потенциал на стыке — пища для размышлений

Другой угол

Code mode переносит проблему безопасности на уровень выше

Если агент сам пишет и исполняет код на лету, аудит «до запуска» не работает — кода ещё нет. Вопрос не «опасны ли скрипты», а готовы ли мы к эфемерному исполняемому артефакту.

Другой угол

Стоимость как новый главный дизайн-фактор harness-ей

$100 за 10 минут делает выбор оркестрации финансовым решением. Победит не самый «динамичный» harness, а тот, кто даст предсказуемый бюджет — как облака выиграли биллингом.

На стыке областей

Геополитика доступа к моделям — новый слой риска инфраструктуры

Приостановка Fable/Mythos для иностранцев показывает: модель — не библиотека «навсегда», а юрисдикционно-зависимый сервис с экспортным контролем.

Смежная область

Сгенерированный одноразовый код — это «инфраструктура как промпт»

240 строк выброшенного кода в data-инженерии/CI означают сдвиг к эфемерным пайплайнам: дешевле перегенерировать, чем поддерживать. Это переворачивает экономику DevOps.

Другой угол

Спор CLAUDE.md vs AGENTS.md повторяет browser wars

Vendor-расширения поверх общего стандарта — это сценарий vendor prefixes в CSS. Либо W3C-подобная стандартизация, либо фрагментация на годы.

На стыке областей

Remote control телефоном — агент как удалённый сотрудник

Меняется ментальная модель: не «запускаешь команду», а делегируешь работнику, проверяемому асинхронно. На стыке с менеджментом — вопросы наблюдаемости и ответственности.
