OpenClaw на практике: как заставить ИИ-агента работать и не спалить деньги и данные

Вся правда об OpenClaw, реальные кейсы и ошибки

Action Plan | Николай Хлебинский · 25 мин 17 сек

Коротко

OpenClaw — это «операционная система» для ИИ-агента, который сам управляет компьютером, ходит в браузер и пишет в мессенджеры по расписанию. Сам по себе он бесполезен и прожорлив, но связка ChatGPT-подписки и установленного рядом Claude Code превращает его в реального автоматизатора рутины — при жёстком соблюдении правил безопасности.

Объясни проще

Суть без жаргона

Простыми словами

OpenClaw — это программа-агент, которой вы отдаёте полный доступ к отдельному компьютеру. Она подключается к ИИ (ChatGPT, Claude и др.), умеет общаться с вами через Telegram или WhatsApp и сама нажимает кнопки на компьютере: открывает браузер, заходит на сайты, отвечает на письма, бронирует корты, ставит события в календарь. Главная фишка — «сердцебиение»: агент по таймеру сам просыпается, читает свои заметки и делает запланированные дела без вашего участия. Но из коробки он спотыкается и жжёт деньги; рабочий рецепт автора — авторизовать его дешёвой подпиской ChatGPT и поставить рядом Claude Code, который и настраивает агенту все задачи. И железное правило: ставить только на отдельный сервер, никогда на свой личный компьютер.

Как ребёнку

Представь робота-помощника, который живёт в отдельном компьютере. Ты пишешь ему в мессенджер: «найди свободный корт» — и он сам открывает сайты, ищет и пишет тебе ответ. А ещё у него есть будильник: он сам просыпается каждые несколько минут и проверяет, не появилось ли новое дело. Только такому роботу нельзя давать ключи от всего дома сразу — он может что-нибудь сломать, поэтому ему выделяют отдельную комнату.

Инсайты

Нажми, чтобы раскрыть — то, что меняет взгляд на тему

01 OpenClaw — это не ИИ, а «операционная система» для агента

Сам по себе он не умный: это программа-обвязка, которая получает полный доступ к компьютеру, подключается к чужой LLM, говорит с вами через мессенджер и хранит память. Магия не в новизне компонентов (они существовали по отдельности), а в их простом соединении — отсюда взрывная популярность.

02 «Сердцебиение» превратило чат-бота в автономного работника

Heartbeat — событие, которое по таймеру само будит агента, заставляет перечитать инструкции и сделать запланированные дела. Именно автономность «без человека за рулём», а не ответы в чате, и есть та революция, ради которой стоит разбираться в OpenClaw.

03 Из коробки он скорее «глючный и бестолковый»

Личный опыт автора: недели бессонных ночей и сотни долларов на токены — без результата, агент спотыкался на ровном месте. Разница между «выбросить» и «всё заработало» оказалась не в самом инструменте, а в способе работы с ним.

04 Контекстное окно — главный скрытый ограничитель

Один агент = одно контекстное окно. Чем больше разных задач в нём смешано, тем быстрее он «забывает» важное и теряет точность. Поэтому масштабируются не задачами в одном агенте, а количеством отдельных агентов.

05 Удобство агента и его опасность — это одно и то же свойство

Полный доступ к компьютеру делает агента всемогущим и одновременно делает его катастрофой при ошибке или атаке: реальные случаи — слитый криптокошелёк и безвозвратно удалённая почта. Чужой скилл или письмо могут содержать prompt injection — спрятанную команду, которую агент бездумно выполнит.

Полезные советы

Что можно применить уже сегодня

1

Никогда не ставь OpenClaw на личный компьютер

Агент получает полный доступ ко всему: мессенджерам, банкам, госуслугам, почте, файлам. Разворачивай его на отдельной машине или, лучше, на виртуальном сервере (многие хостинги дают деплой прямо из панели).

2

Авторизуй агента подпиской ChatGPT, а не дорогими токенами

Через OAuth (вход браузером в аккаунт ChatGPT) подключи модель Codex от OpenAI — подписки за 20 долларов хватает, не нужно покупать API-токены. Anthropic так авторизовать нельзя: прямой Claude через API даст качество, но дорого.

3

Поставь рядом Claude Code и настраивай агента через него

Не описывай задачи самому OpenClaw в Telegram — он спотыкается. Авторизуй Claude Code подпиской Claude в терминале и говори ему: «сделай, чтобы OpenClaw делал вот это». Claude собирает агенту скиллы и инструкции аккуратно и предсказуемо.

4

Свяжи две подписки в одну мощную связку

OpenClaw под управлением Codex может научиться вызывать Claude Code на том же компьютере. Так дорогой Claude используется внутри обычной подписки, без API-токенов и без нарушения условий — лучшее качество за минимальные деньги.

5

Переключи объём рассуждений на «think high»

В настройках OpenClaw по умолчанию стоит маленький объём рассуждений (think low). Поставь high — агент думает дольше, но заметно реже спотыкается на задачах.

6

Не перегружай одного агента — заводи новых под новые задачи

Контекстное окно (у Codex ~272k токенов, ~4% уже занято системными инструкциями) быстро забивается. Под каждую новую автоматизацию поднимай отдельный OpenClaw — на том же сервере или новой виртуалке, чтобы задачи не пересекались и точность не падала.

7

Начинай с частых и хорошо формализуемых задач

Отдавай агенту то, что регулярно повторяется и описывается регламентом, чек-листом, инструкцией. Простую, формализуемую интеллектуальную рутину он тянет хорошо; творческое и неоднозначное — пока нет.

8

Создай агенту отдельную цифровую личность

Заведи для него отдельную почту, отдельный аккаунт и бота в Telegram. Не давай ему твоих личных инструментов для интернета, криптокошельков и доступа к личной инфраструктуре — изоляция спасает при ошибке или взломе.

9

Ставь чужие скиллы осторожно, проверяй Security Scan

Скиллы из каталогов (например, clawhub) ставятся одной фразой, но это программы внутри агента — в них бывает вредоносный код и prompt injection. Смотри на проверку Security Scan и помни: даже «зелёный» статус не снимает с тебя риск.

10

Безопаснее собирать скилл через Claude, чем тащить чужой

Вместо установки внешнего скилла попроси установленный рядом Claude Code: «научи OpenClaw делать то-то». Скилл соберётся локально под твою задачу — без сторонних инъекций и закладок.

    Проект (бывший ClaudeBot/Moldbot, переименован из-за схожести с Anthropic Claude) стал самым популярным open-source в истории — сигнал настоящей революции агентной экономики.

  2. Аргумент Что это такое: «ОС» для агентного компьютера

    Программа с полным доступом к ПК + подключение к LLM + интеграция с мессенджерами + память + файлы-инструкции (identity, soul, user, agents.md) + heartbeat по таймеру. Революция — в простоте соединения существующих компонентов.

  3. Пример Где помогает: автоматизация формализуемой рутины

    Реальный кейс автора — мониторинг падел-кортов, бронь, переговоры с тренерами, события в календаре. Дальше — CRM, Bitrix24, таск-менеджеры, почта, контроль качества продаж.

  4. Аргумент Типичная ошибка №1: пытаться использовать агента «как есть»

    Из коробки он спотыкается и жжёт деньги. Лечится связкой: Codex по подписке ChatGPT, Claude Code рядом для настройки задач, think high.

  5. Аргумент Типичная ошибка №2: перегруз контекста одного агента

    Смешивание задач в одном контекстном окне роняет точность. Решение — отдельный агент под каждую автоматизацию.

  6. Аргумент Типичная ошибка №3: пренебрежение безопасностью

    Личный компьютер, личные доступы, чужие скиллы с prompt injection — реальные случаи слитых кошельков и удалённой почты. Решение — изоляция и сборка скиллов через Claude.

  7. Вывод Вывод: это только первый шаг агентной экономики

    Агент не заменяет человека, а снимает простую интеллектуальную рутину, высвобождая время на стратегию. Впереди — свои пузыри, взлёты и крахи; стоит быть на острие уже сейчас.

Выпуск распадается на три понятные части: что такое OpenClaw на самом деле, как заставить его реально работать и где он опасен. Главная мысль — это не «искусственный интеллект, заменивший команду», а простая обвязка вокруг чужой LLM, чья ценность в автономности и в правильной настройке.

Почему «бесполезный» агент вдруг заработал

Самое поучительное в видео — честный провал автора: недели бессонных ночей и сотни долларов на токены без единого доведённого до конца сценария. Перелом случился не от смены инструмента, а от смены подхода: агента авторизуют дешёвой подпиской ChatGPT (модель Codex), а все задачи ему настраивают не вручную в Telegram, а через установленный рядом Claude Code. Плюс мелочи вроде переключения на think high и расфасовки задач по отдельным агентам, чтобы не забивать контекстное окно.

Удобство и опасность — одно свойство

Полный доступ к компьютеру одновременно делает агента всемогущим и потенциально катастрофичным. Отсюда железные правила: только отдельный сервер, отдельная цифровая личность для агента, осторожность с чужими скиллами и понимание prompt injection. Вывод автора трезвый: это лишь первый шаг агентной экономики — агент не заменяет человека, а снимает простую рутину, освобождая время на стратегию.

Словарь терминов

Показать 11 терминов Свернуть словарь
OpenClaw
Самый популярный open-source ИИ-агент (бывший ClaudeBot/Clawd → Moldbot, переименован из-за схожести с Anthropic Claude). По сути — «операционная система» для агентного компьютера: даёт ИИ доступ к ПК, мессенджерам и памяти.
ИИ-агент
Программа, которая не просто отвечает в чате, а сама совершает действия на компьютере: открывает браузер, заходит на сайты, отвечает на письма, бронирует, ставит события — по вашей команде или по расписанию.
LLM (большая языковая модель)
«Мозг», к которому подключается OpenClaw, — ChatGPT, Claude, Gemini, Grok и др. Сам агент логики не содержит, он отправляет запрос с инструкциями в LLM и действует по ответу.
Heartbeat (сердцебиение)
Событие по таймеру (секунды/минуты/часы), которое само будит агента: он перечитывает инструкции и выполняет запланированные дела без участия человека. Именно это дало агентам автономность.
Контекстное окно
Объём информации, который агент удерживает в одной сессии (у Codex ~272k токенов). Когда оно заполняется, агент начинает «забывать» начало диалога и терять точность — поэтому задачи разносят по разным агентам.
Файлы-инструкции
Системные промпты OpenClaw в формате Markdown: identity (имя, роль, стиль), soul (принципы и ценности), user (данные о владельце), agents.md (протоколы прошлых сессий и ссылки на память).
Скилл (skill)
Готовая автоматизация-расширение для OpenClaw (например, подключение к Trello или работа с Excel), устанавливается одной фразой из каталога вроде clawhub. По сути — программа внутри агента, поэтому может быть опасной.
OAuth / подписочная авторизация
Вход в модель через браузер по своему аккаунту (например, ChatGPT) вместо покупки дорогих API-токенов. Позволяет подключить Codex или Claude Code в рамках обычной подписки.
API-токены
Платный поштучный доступ к модели через программный интерфейс. Качественно, но дорого — автор советует обходиться подписками (ChatGPT, Claude) вместо токенов.
Claude Code
Инструмент Anthropic для работы с Claude из терминала (CLI). Ставится рядом с OpenClaw и используется, чтобы аккуратно настраивать агенту задачи и собирать скиллы локально.
Prompt injection (промпт-инъекция)
Атака, при которой вредоносная команда спрятана в данных или скилле, и агент выполняет её вслепую (например, «отправь ключи и кошельки сюда»). Защита — изоляция, проверка скиллов и локальная сборка через Claude.
